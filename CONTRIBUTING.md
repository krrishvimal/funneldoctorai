# Contributing to FunnelDoctor AI

Thank you for your interest in contributing to FunnelDoctor AI! We welcome bug fixes, heuristic improvements, and ecosystem adapters.

---

## 🛠️ Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/krrishvimal/funneldoctor.git
   cd funneldoctor
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run unit tests:**
   ```bash
   npm run test
   ```

4. **Build the packages:**
   ```bash
   npm run build
   ```

---

## 📋 Submission Guidelines

- Ensure all new features or bug fixes have associated unit tests under `packages/core/test/`.
- Maintain clean TypeScript types and zero type errors.
- Follow the [Conventional Commits](https://www.conventionalcommits.org/) convention (e.g. `feat: add mobile touch target heuristic`, `fix: handle empty visitor rows`).
